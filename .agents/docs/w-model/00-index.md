# W-Model 開発規約

この文書は、Wモデル開発における成果物、検証、正本、配置、識別子の共通ルールへの入口です。機能ごとの要件・設計・テスト方法は各Featureの文書で定めます。

## 共通ルール

- [共通原則と成果物管理](01-common-principles.md)：開発成果物と検証の対応、SSOTと配置、識別子、AIDEとの責務分担。

## 適用範囲

ここではWモデルに関する開発成果物と検証の設計を定めます。Issue、PR、ブランチ、コミット、Project Status、レビュー記録などの作業管理は[AIDE開発ルール](../aide/00_index.md)に従います。

## 変更時の原則

1. 要件・設計を作るときに、対応する検証観点と期待結果も定義します。
2. 成果物の正本を一つに定め、他の文書からは参照します。同期が必要な重複記述を避けます。
3. 成果物間の参照には安定した識別子を使い、変更時にトレーサビリティを更新します。
4. 未確定の要件・判断は明示し、必要な人間の承認を得るまで確定事項として扱いません。
