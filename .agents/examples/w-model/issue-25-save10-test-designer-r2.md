## Test case

| 項目 | 内容 |
|---|---|
| Test ID | `TEST-SAVE10-R2-001` |
| 種別 | Feature受入テスト（計算・表示） |
| 対応要件 | SAVE10有効時の割引計算、送料の割引除外、税計算・丸め、割引額と最終金額の表示 |
| 前提 | 商品小計100円、送料10円、税率10%。有効な割引コード `SAVE10`（割引率10%）を入力できる。 |
| 操作 | `SAVE10` を適用して注文金額を計算し、画面に表示された割引額と最終金額を確認する。 |
| 期待値 | 割引額10円、税額10円、最終金額110円が表示される。送料10円は割引対象外。 |
| 合格条件 | 表示割引額が10円、表示最終金額が110円であり、税額の計算・表示が10円である。 |

## 根拠計算

1. 割引額: 商品小計100円 × 10% = **10円**。割引対象は商品小計のみ。
2. 割引後商品小計: 100円 − 10円 = **90円**。
3. 課税基礎: 割引後商品小計90円 + 送料10円 = **100円**。
4. 税額: 100円 × 10% = 10円。1円単位四捨五入後も **10円**。
5. 最終金額: 90円 + 送料10円 + 税額10円 = **110円**。
